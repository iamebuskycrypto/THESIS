Paper decision model

The key stays in this local app's memory and is sent only to the endpoint you provide.

Online providers must use HTTPS. A local model may use http://127.0.0.1:11434/v1/chat/completions.
It is not saved to a file or browser storage. Restarting the app clears it.

This sends a small connection-test request. An online provider may charge; a local model uses your own computer.

Start in three steps

  1. Launch the downloaded project with python3 launch.py and open the local address it prints.
  2. Connect an online model here, or run an OpenAI-compatible local model first and use its loopback endpoint.
  3. Refresh the inputs. Once the data is eligible, run one paper cycle and inspect the result before starting continuous monitoring.
No Bitget trading key is needed for the local simulator. Local-model HTTP is accepted only on your own computer; every other provider must use HTTPS.

What remains to prove

The agent still needs genuine model-backed forward logs and a measured comparison against a simple rule. A working interface is not evidence of investment performance.
